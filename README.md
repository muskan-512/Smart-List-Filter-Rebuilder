# Smart-List-Filter-Rebuilder
A Python application that takes a mixed list of numbers and strings, separates them into different lists, counts each category, and displays results based on a selected section (A, B, or C). Demonstrates list handling, filtering logic, and conditional branching.

📌 Project Title

Smart List Filter & Section-Based Display System

📖 Description

This program:

Takes a mixed list (numbers and strings)

Separates them into:

Number List

String List

Displays output based on section selection (A, B, C)

⚙️ Working Logic
Step 1: Input List

User enters size of list

User enters items

Program separates numbers and strings

Step 2: Section-Based Output
Section	Output
A	Number list + count
B	String list + count
C	Both lists + both counts
Other	Invalid section
▶️ How to Run
python filename.py

📤 Sample Output
Number list: [10, 20]
Number count: 2
